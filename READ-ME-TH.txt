หน้า Home — Colorful 3D Surface

วิธีใช้กับเว็บไซต์เดิม
แตก ZIP แล้วนำ 3 ไฟล์นี้ไปวางในโฟลเดอร์เดียวกับ index.html ของเว็บไซต์:
1. index.html (แทนไฟล์เดิม)
2. home-surface.css
3. home-surface.js
อย่าวาง 3 ไฟล์ไว้ในโฟลเดอร์ย่อย และเก็บไฟล์อื่นของเว็บไซต์เดิมไว้ทั้งหมด
ชุดนี้เป็นแพตช์หน้า Home ต้องใช้ร่วมกับไฟล์เว็บไซต์เดิม ไม่ใช่เว็บไซต์ครบชุด
home.css และ home-motion.js รุ่นก่อนเก็บไว้ได้ แต่หน้า Home ใหม่นี้ไม่เรียกใช้แล้ว

สิ่งที่เปลี่ยน
- พื้นหลังกราฟ Canvas ครอบคลุมพื้นที่เปิดหน้า Home เต็มความกว้างและอย่างน้อยความสูงจอหักแถบนำทาง
- พื้นหลังน้ำเงินเข้ม พร้อมแสงสีม่วงและฟ้า ไม่มีพื้นหลังสีขาวแบบเดิม
- ตาข่ายพื้นผิว f(x,y)=sin(x)cos(y) ไล่สีฟ้า ม่วง และชมพู
- เส้นสีทองบนพื้นผิว พร้อมจุดเคลื่อนที่และภาพฉายบนระนาบด้านล่าง
- มุมมองกราฟแกว่งช้า ๆ โดยพื้นผิวยังคงตรงตามฟังก์ชันเดิม
- ปุ่มเล่น/หยุด ไทย/อังกฤษ รองรับการตั้งค่าลดการเคลื่อนไหว
- หยุดวาดเมื่อกราฟอยู่นอกจอหรือแท็บถูกซ่อน
- ปรับสีส่วนอื่นของหน้า Home ให้สอดคล้องกัน รองรับ dark mode
- เก็บสมการเดิม เมนู และส่วนเรียนรู้เดิมไว้ ไม่แก้หน้าบทเรียนอื่น

ตรวจแล้ว
ตรวจ syntax JavaScript; ทดสอบ Canvas ด้วย context จำลองที่ 1440x900, 768x1024,
375x900 และ 320x850; พิกัดวาดเป็นค่าจำกัด; จุดเคลื่อนที่เปลี่ยนตำแหน่ง;
ปุ่มหยุด/เล่น; reduced motion; ข้อความไทย/อังกฤษ; สมการเดิมและ ID ของส่วนเรียนรู้;
ลิงก์ภายในหน้าและการอ้างอิงไฟล์ที่จำเป็น
ยังไม่ได้ตรวจภาพและความลื่นบน Safari/iPhone จริง

ชุดไฟล์นี้ยังไม่ได้อัปโหลดขึ้น GitHub หรือเปลี่ยนเว็บจริงให้คุณ
หลังอัปโหลดครบ รอ GitHub Pages deploy เสร็จ แล้วโหลดหน้าใหม่
