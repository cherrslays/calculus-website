สาเหตุที่พบ:
HTML และ calculator-worker.js เรียกไฟล์จาก vendor/ แต่ไฟล์จริงอยู่ระดับเดียวกับ index.html

สิ่งที่แก้:
- แก้เส้นทางไฟล์ทุกหน้าและเครื่องคิดเลขให้ใช้ไฟล์ที่อยู่ระดับเดียวกัน
- แปลงสมการ 779 จุดเป็น SVG ภายใน HTML รวมทั้งภาษาไทย อังกฤษ และเฉลยที่พับอยู่
- สมการบทเรียนแสดงได้โดยไม่ต้องรอ JavaScript หรือฟอนต์สมการจากภายนอก
- เก็บเครื่องคิดเลข กราฟ แบบฝึกหัด 60 ข้อ ภาษาไทย/อังกฤษ และ dark mode
- เปลี่ยนเวอร์ชัน URL ของไฟล์เพื่อไม่ให้ใช้ JavaScript/CSS เก่าจากแคช

วิธีอัปโหลด:
1. แตก ZIP นี้ก่อน ไม่ใช่อัปโหลดไฟล์ ZIP ขึ้น GitHub
2. เลือกไฟล์ทั้งหมดที่แตกออกมา อัปโหลดให้อยู่ระดับเดียวกับ index.html ของ repository
3. ไม่ต้องสร้างโฟลเดอร์ vendor และไม่ต้องวางในโฟลเดอร์ซ้อนอีกชั้น
4. รอ GitHub Pages เผยแพร่เสร็จ แล้วปิดแท็บเดิมและเปิดเว็บใหม่
5. หากยังเห็นหน้าเดิม ลองเปิดด้วยแท็บส่วนตัวเพื่อแยกปัญหาแคช

การตรวจสอบ:
ตรวจสมการ 779 จุด ไม่มีข้อผิดพลาด TeX; ตรวจเส้นทางไฟล์และลิงก์ภายในทุกหน้า
ทดสอบเปลี่ยนภาษา dark mode การแปลงสมการใหม่ และ worker ของเครื่องคิดเลขทั้งสอง
เป็นการตรวจด้วย DOM/เครื่องคำนวณ ไม่ใช่การยืนยันภาพบน Safari ของอุปกรณ์จริง
