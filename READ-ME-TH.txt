ปรับหน้า Home — Calculus Atlas

ใช้ไฟล์หน้า Home ล่าสุดจาก GitHub เป็นฐาน และรักษาสมการที่แปลงไว้แล้ว
ออกแบบภาพกราฟิก SVG ใหม่เอง ไม่ได้ใช้ภาพปกหนังสือหรือชื่อผู้เขียนจากภาพอ้างอิง

วิธีใช้งาน
1. แตก ZIP
2. อัปโหลด index.html และ home.css ไว้ระดับเดียวกับ index.html เดิมใน repository
3. index.html ใช้แทนไฟล์เดิม ส่วน home.css เป็นไฟล์ใหม่
4. ไม่ต้องแทน styles.css หรือไฟล์ของบทเรียนอื่น
5. รอ GitHub Pages เผยแพร่เสร็จแล้วเปิดเว็บใหม่

สิ่งที่เปลี่ยน
- ส่วนต้อนรับใหม่ โทนกระดาษ เขียวอมฟ้า และดินเผา
- กราฟิกอินทิกรัลและเส้นโค้ง SVG ที่ออกแบบใหม่
- การ์ดบทเรียนพร้อมภาพกราฟเล็ก ๆ และจุดเข้าสู่แบบฝึกหัด
- จัดสมการทฤษฎีบทมูลฐานไว้ในแถบอธิบายใต้ส่วนต้อนรับ
- รองรับภาษาไทย/อังกฤษ โหมดมืด และรูปแบบหน้าจอเล็ก

ยังคงระบบค้นหา ลิงก์บทเรียน แบบฝึกหัด และเครื่องพล็อตกราฟเดิม
ไม่ได้อัปโหลดหรือเปลี่ยนแปลง GitHub ให้คุณ

ผลตรวจ: ID และสมการเดิมอยู่ครบ ลิงก์และไฟล์อ้างอิงถูกต้อง
ทดสอบการสลับภาษา โหมดมืด ระบบค้นหา และเครื่องพล็อตกราฟผ่าน
ไม่พบปัญหาในชุดตรวจโครงสร้าง accessibility ที่ใช้
ยังไม่ได้ตรวจภาพจริงบน Safari/มือถือ จึงควรดูอีกครั้งหลังอัปโหลด
