# Calculus Atlas
A modern university-style bilingual calculus website for GitHub Pages.

## Pages
- `index.html` — home + search + function grapher
- `limits.html` — detailed limits chapter
- `derivatives.html` — detailed derivatives chapter + tangent visualizer + derivative calculator
- `integrals.html` — detailed integrals chapter + Riemann visualizer + integral calculator
- `practice.html` — practice problems with revealable solutions

## Deploy
Upload all files to the root of a GitHub repository and enable GitHub Pages from the `main` branch `/ (root)`.

The site loads MathJax, math.js, Nerdamer, and Google Fonts from CDNs, so internet access is required for full functionality.
