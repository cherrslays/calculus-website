Derivatives อนุพันธ์

The derivative converts nearby change into an instantaneous rate. Geometrically, it is the slope of the tangent line; physically, it is velocity from position. อนุพันธ์เปลี่ยน “การเปลี่ยนแปลงในช่วงเล็ก ๆ” ให้เป็นอัตราการเปลี่ยนแปลงฉับพลัน ทางเรขาคณิตคือความชันเส้นสัมผัส และทางฟิสิกส์คือความเร็วจากตำแหน่ง

1. Definition from a limit 1. นิยามจากลิมิต

$$f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}$$

The fraction is an average rate of change over a small interval. Letting $h\to0$ produces the instantaneous rate. เศษส่วนนี้คืออัตราการเปลี่ยนแปลงเฉลี่ยในช่วงเล็ก ๆ และเมื่อให้ $h\to0$ จะได้อัตราการเปลี่ยนแปลงฉับพลัน

From first principles จากนิยาม

For $f(x)=x^2$: สำหรับ $f(x)=x^2$:

$$\frac{(x+h)^2-x^2}{h}=\frac{2xh+h^2}{h}=2x+h$$ $$f'(x)=\lim_{h\to0}(2x+h)=2x$$
Differentiability implies continuity, but continuity does not guarantee differentiability. Example: $|x|$ is continuous at $0$ but has a corner there. ถ้าหาอนุพันธ์ได้ย่อมต่อเนื่อง แต่ความต่อเนื่องไม่ได้รับประกันว่าจะหาอนุพันธ์ได้ เช่น $|x|$ ต่อเนื่องที่ 0 แต่มีมุมแหลม

2. Differentiation rules 2. กฎการหาอนุพันธ์

Power rule กฎยกกำลัง $$\frac{d}{dx}x^n=nx^{n-1}$$
Product rule กฎผลคูณ $$\frac{d}{dx}(uv)=u'v+uv'$$
Quotient rule กฎผลหาร $$\left(\frac uv\right)'=\frac{u'v-uv'}{v^2}$$
Chain rule กฎลูกโซ่ $$\frac{d}{dx}f(g(x))=f'(g(x))g'(x)$$

Common derivatives อนุพันธ์พื้นฐานที่ควรรู้

$$(e^x)'=e^x,\qquad (\ln x)'=\frac1x$$
$$(\sin x)'=\cos x,\qquad (\cos x)'=-\sin x$$
$$(\tan x)'=\sec^2x$$
$$(a^x)'=a^x\ln a$$
Chain rule example ตัวอย่างกฎลูกโซ่ $$y=(3x^2+1)^5$$ $$y'=5(3x^2+1)^4\cdot6x=30x(3x^2+1)^4$$
Apply rules only where the functions are differentiable. Quotients require a nonzero denominator; ln x requires x > 0; aˣ assumes a > 0. For a general real exponent n, the power rule holds on x > 0 and on other real intervals where the power is defined and differentiable. ใช้กฎเมื่อฟังก์ชันหาอนุพันธ์ได้ กฎผลหารต้องมีตัวส่วนไม่เป็นศูนย์ ln x ต้องมี x > 0 และ aˣ สมมติ a > 0 สำหรับกำลังจริง n กฎยกกำลังใช้บน x > 0 และช่วงค่าจริงอื่นที่ฟังก์ชันนิยามและหาอนุพันธ์ได้

4. Applications of derivatives 4. การประยุกต์อนุพันธ์

Increasing and decreasing ช่วงเพิ่มและช่วงลด

If $f'(x)>0$ throughout an interval, the function is strictly increasing there; if $f'(x)<0$ throughout, it is strictly decreasing. ถ้า $f'(x)>0$ ตลอดช่วง ฟังก์ชันจะเพิ่มอย่างเคร่งครัดในช่วงนั้น และถ้า $f'(x)<0$ ตลอดช่วง ฟังก์ชันจะลดอย่างเคร่งครัด

Optimization การหาค่าสูงสุด/ต่ำสุด

Find critical points where $f'(x)=0$ or $f'$ is undefined, then classify them using sign changes or the second derivative. หาจุดวิกฤตจาก $f'(x)=0$ หรือจุดที่ $f'$ ไม่มีค่า จากนั้นจำแนกด้วยเครื่องหมายของอนุพันธ์หรืออนุพันธ์อันดับสอง

Optimization example ตัวอย่างการหาค่าสุดขั้ว

For $f(x)=-x^2+6x+1$, $f'(x)=-2x+6=0$ gives $x=3$. Since $f''(x)=-2<0$, this point is a local maximum. สำหรับ $f(x)=-x^2+6x+1$ จะได้ $f'(x)=-2x+6=0$ ดังนั้น $x=3$ และเพราะ $f''(x)=-2<0$ จุดนี้เป็นค่าสูงสุดเฉพาะที่

Motion การเคลื่อนที่

$$v(t)=s'(t),\qquad a(t)=v'(t)=s''(t)$$

6. Implicit and logarithmic differentiation 6. อนุพันธ์โดยปริยายและลอการิทึม

When x and y are related by an equation, treat y as a function of x. Each derivative involving y needs the chain rule. เมื่อ x และ y สัมพันธ์กันด้วยสมการ ให้มอง y เป็นฟังก์ชันของ x ทุกครั้งที่หาอนุพันธ์พจน์ที่มี y ต้องใช้กฎลูกโซ่

A circle วงกลม
$$x^2+y^2=25\quad\Longrightarrow\quad 2x+2y\frac{dy}{dx}=0\quad\Longrightarrow\quad\frac{dy}{dx}=-\frac{x}{y}$$

At (3,4), the slope is −3/4. The formula requires y ≠ 0; at (±5,0) the circle has vertical tangents and cannot locally be a differentiable graph y(x). ที่ (3,4) ความชันเท่ากับ −3/4 สูตรนี้ต้องมี y ≠ 0 ที่ (±5,0) วงกลมมีเส้นสัมผัสแนวตั้ง และไม่สามารถเขียนเป็นกราฟ y(x) ที่หาอนุพันธ์ได้ในบริเวณนั้น

For variable bases and exponents, take logarithms before differentiating. The real-valued function xˣ below is considered on x > 0. เมื่อทั้งฐานและเลขชี้กำลังเป็นตัวแปร ให้ใช้ลอการิทึมก่อนหาอนุพันธ์ ฟังก์ชันค่าจริง xˣ ด้านล่างพิจารณาบนโดเมน x > 0

$$y=x^x\;\Rightarrow\;\ln y=x\ln x\;\Rightarrow\;\frac{y'}y=\ln x+1\;\Rightarrow\;y'=x^x(\ln x+1)$$

7. Mean Value Theorem 7. ทฤษฎีบทค่ากลาง

Mean Value Theorem ทฤษฎีบทค่ากลาง

If f is continuous on [a,b] and differentiable on (a,b), with a < b, there is a point c inside the interval whose tangent slope equals the average rate over the whole interval. ถ้า f ต่อเนื่องบน [a,b] และหาอนุพันธ์ได้บน (a,b) โดย a < b จะมีจุด c ภายในช่วงที่ความชันเส้นสัมผัสเท่ากับอัตราการเปลี่ยนแปลงเฉลี่ยตลอดช่วง

$$f'(c)=\frac{f(b)-f(a)}{b-a},\qquad c\in(a,b)$$

Rolle’s theorem is the special case f(a) = f(b), giving f′(c) = 0. The hypotheses matter: |x| on [−1,1] has equal endpoint values but no horizontal tangent because it is not differentiable at zero. ทฤษฎีบทของโรลล์เป็นกรณีพิเศษเมื่อ f(a) = f(b) จึงได้ f′(c) = 0 เงื่อนไขมีความสำคัญ เช่น |x| บน [−1,1] มีค่าที่ปลายเท่ากันแต่ไม่มีเส้นสัมผัสแนวนอน เพราะหาอนุพันธ์ที่ศูนย์ไม่ได้

Find the guaranteed point หาจุดที่ทฤษฎีบทรองรับ

For f(x) = x² on [1,3], the secant slope is (9−1)/(3−1) = 4. Solve 2c = 4 to obtain c = 2, which lies in (1,3). สำหรับ f(x) = x² บน [1,3] ความชันเส้นตัดเท่ากับ (9−1)/(3−1) = 4 แก้ 2c = 4 ได้ c = 2 ซึ่งอยู่ใน (1,3)

8. Curve analysis and global extrema 8. วิเคราะห์กราฟและค่าสุดขั้วสัมบูรณ์

A critical number is an interior point in the domain where f′ is zero or does not exist. On a closed bounded interval, a continuous function attains its absolute maximum and minimum. Compare all critical values and both endpoint values. จำนวนวิกฤตคือจุดภายในโดเมนที่ f′ เป็นศูนย์หรือไม่มีค่า ฟังก์ชันต่อเนื่องบนช่วงปิดที่มีขอบเขตจะมีค่าสูงสุดและต่ำสุดสัมบูรณ์ ให้เปรียบเทียบค่าที่จุดวิกฤตทั้งหมดและปลายช่วงทั้งสอง

$$f(x)=x^3-3x,\quad f'(x)=3(x-1)(x+1),\quad f''(x)=6x$$

On [−2,2], test x = −2, −1, 1, 2. The corresponding values are −2, 2, −2, 2. The maximum is 2 and the minimum is −2; both can occur at multiple points. The curve is concave down for x < 0 and concave up for x > 0, so (0,0) is an inflection point. บน [−2,2] ตรวจ x = −2, −1, 1, 2 ได้ค่าฟังก์ชัน −2, 2, −2, 2 ตามลำดับ ค่าสูงสุดคือ 2 และต่ำสุดคือ −2 ซึ่งอาจเกิดที่หลายจุด กราฟเว้าลงเมื่อ x < 0 และเว้าขึ้นเมื่อ x > 0 ดังนั้น (0,0) เป็นจุดเปลี่ยนเว้า

Common mistake ข้อผิดพลาดที่พบบ่อย

The equation f″(c) = 0 only identifies a candidate inflection point; concavity must change. For x⁴, f″(0) = 0 but there is no inflection. Likewise, f″(c) = 0 makes the second derivative test inconclusive. สมการ f″(c) = 0 ให้เพียงจุดที่อาจเปลี่ยนเว้า ต้องตรวจว่าความเว้าเปลี่ยนจริง สำหรับ x⁴ มี f″(0) = 0 แต่ไม่เปลี่ยนเว้า และถ้า f″(c) = 0 การทดสอบอนุพันธ์อันดับสองยังสรุปไม่ได้

9. Related rates and linear approximation 9. อัตราสัมพัทธ์และการประมาณเชิงเส้น

An expanding sphere ทรงกลมที่กำลังขยาย

A sphere’s radius grows at 2 cm/s. Differentiate V = 4πr³/3 with respect to time before substituting r = 3 cm. รัศมีทรงกลมเพิ่มด้วยอัตรา 2 ซม./วินาที หาอนุพันธ์ V = 4πr³/3 เทียบกับเวลาก่อนแทน r = 3 ซม.

$$\frac{dV}{dt}=4\pi r^2\frac{dr}{dt}=4\pi(3)^2(2)=72\pi\;\mathrm{cm^3/s}$$

A tangent line also provides a local approximation. For differentiable f near a, L(x) = f(a) + f′(a)(x−a). It is accurate near a, but is not an exact equality in general. เส้นสัมผัสใช้ประมาณค่าใกล้จุดได้ด้วย ถ้า f หาอนุพันธ์ได้ใกล้ a ให้ L(x) = f(a) + f′(a)(x−a) การประมาณแม่นยำใกล้ a แต่โดยทั่วไปไม่ใช่สมการที่เท่ากันพอดี

$$\sqrt{4.1}\approx \sqrt4+\frac{1}{2\sqrt4}(4.1-4)=2.025$$

For Newton’s method, the tangent’s x-intercept becomes the next guess: xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ). A zero derivative, a poor starting guess, or a discontinuity can prevent convergence. สำหรับวิธีนิวตัน ใช้จุดตัดแกน x ของเส้นสัมผัสเป็นค่าประมาณถัดไป: xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ) หากอนุพันธ์เป็นศูนย์ ค่าเริ่มต้นไม่เหมาะสม หรือมีจุดไม่ต่อเนื่อง อาจไม่ลู่เข้า

Inverse functions & higher implicit derivatives ฟังก์ชันผกผันและอนุพันธ์โดยปริยายอันดับสูง

If f is one-to-one near a, its inverse is continuous near b=f(a), and f is differentiable at a with f′(a)≠0, then its inverse is differentiable at b. Differentiate f(f⁻¹(y))=y by the chain rule. หาก f เป็นหนึ่งต่อหนึ่งใกล้ a ฟังก์ชันผกผันต่อเนื่องใกล้ b=f(a) และ f หาอนุพันธ์ได้ที่ a โดย f′(a)≠0 ฟังก์ชันผกผันจะหาอนุพันธ์ได้ที่ b หาอนุพันธ์ f(f⁻¹(y))=y ด้วยกฎลูกโซ่

$$(f^{-1})'(b)=\frac1{f'(a)},\qquad (\arcsin x)'=\frac1{\sqrt{1-x^2}}\ (|x|<1),\qquad(\arctan x)'=\frac1{1+x^2}$$

These domains belong to the derivative formulas, not just to the functions. Arcsine is defined at ±1, but has no finite derivative there. In a composite, simplify square roots with √(u²)=|u| and examine exceptional points separately. โดเมนเหล่านี้เป็นของสูตรอนุพันธ์ ไม่ใช่เพียงของฟังก์ชัน arcsine นิยามที่ ±1 แต่ไม่มีอนุพันธ์จำกัดที่นั่น สำหรับฟังก์ชันประกอบ ให้จัดรากด้วย √(u²)=|u| และตรวจจุดยกเว้นแยกกัน

Differentiate an equation before substituting a point หาอนุพันธ์สมการก่อนแทนจุด

$$x^2+xy+y^2=3\quad\Rightarrow\quad2x+y+(x+2y)y'=0$$
$$2+2y'+2(y')^2+(x+2y)y''=0$$

The second differentiation uses the product rule on both xy′ and yy′. At (1,1), first find y′=−1 and then substitute into the second equation to obtain y″=−2/3. Substituting y=1 before differentiating would incorrectly treat a changing quantity as constant. การหาอนุพันธ์ครั้งที่สองใช้กฎผลคูณกับทั้ง xy′ และ yy′ ที่ (1,1) หา y′=−1 ก่อนแล้วแทนในสมการที่สองได้ y″=−2/3 หากแทน y=1 ก่อนหาอนุพันธ์จะถือปริมาณที่เปลี่ยนเป็นค่าคงที่อย่างผิดพลาด

Worked problem: the absolute value in an arcsine composite โจทย์พร้อมวิธีทำ: ค่าสัมบูรณ์ในฟังก์ชันประกอบ arcsine

Exam problem: a variable exponent and a quotient แนวสอบ: เลขชี้กำลังแปรผันร่วมกับผลหาร
