Limits ลิมิต Derivatives อนุพันธ์ Integrals ปริพันธ์

Limits ลิมิต

Limit · Easy ลิมิต · พื้นฐาน

$$\lim_{x\to4}\frac{x^2-16}{x-4}$$

Step-by-step solution เฉลยทีละขั้นตอน

Factor the numerator: แยกตัวประกอบ:

$$\frac{(x-4)(x+4)}{x-4}=x+4$$ $$\therefore\;\lim_{x\to4}\frac{x^2-16}{x-4}=8$$
Limit · Medium ลิมิต · ประยุกต์

$$\lim_{x\to0}\frac{\sqrt{1+3x}-1}{x}$$

Step-by-step solution เฉลยทีละขั้นตอน

Multiply by the conjugate. คูณด้วยพจน์สังยุค

$$\frac{\sqrt{1+3x}-1}{x}\cdot\frac{\sqrt{1+3x}+1}{\sqrt{1+3x}+1}=\frac{3}{\sqrt{1+3x}+1}\to\frac32$$
Limit · Concept ลิมิต · แนวคิด

If $\lim_{x\to2^-}f(x)=5$ and $\lim_{x\to2^+}f(x)=7$, what is $\lim_{x\to2}f(x)$? ถ้า $\lim_{x\to2^-}f(x)=5$ และ $\lim_{x\to2^+}f(x)=7$ แล้ว $\lim_{x\to2}f(x)$ มีค่าเท่าใด?

Step-by-step solution เฉลยทีละขั้นตอน

It does not exist because the one-sided limits are different. ไม่มีลิมิตสองด้าน เพราะลิมิตซ้ายและขวามีค่าไม่เท่ากัน

Foundation พื้นฐาน

04. Polynomial substitution แทนค่าในพหุนาม

$$\lim_{x\to2}(x^3-2x+1)$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. A polynomial is continuous everywhere, so direct substitution is valid. พหุนามต่อเนื่องทุกจุด จึงแทนค่าตรง ๆ ได้
  2. Substitute $x=2$: $2^3-2(2)+1$. แทน $x=2$: $2^3-2(2)+1$
  3. Simplify: 8 − 4 + 1 = 5. จัดรูป: 8 − 4 + 1 = 5
Foundation พื้นฐาน

05. Scaled sine ลิมิต sine ที่ปรับสเกล

$$\lim_{x\to0}\frac{\sin5x}{2x}$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. Rewrite as $\frac52\frac{\sin5x}{5x}$. เขียนเป็น $\frac52\frac{\sin5x}{5x}$
  2. Let u = 5x. Then u tends to zero and sin(u)/u tends to 1 in radians. ให้ u = 5x แล้ว u เข้าใกล้ศูนย์ และ sin(u)/u เข้าใกล้ 1 เมื่อใช้เรเดียน
  3. The answer is $5/2$. คำตอบคือ $5/2$
Foundation พื้นฐาน

06. Dominant powers พจน์กำลังสูงสุด

$$\lim_{x\to\infty}\frac{3x^2-x+2}{2x^2+5}$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. Divide every term by $x^2$. หารทุกพจน์ด้วย $x^2$
  2. The quotient becomes $(3-1/x+2/x^2)/(2+5/x^2)$. ได้ $(3-1/x+2/x^2)/(2+5/x^2)$
  3. The reciprocal terms tend to zero, giving 3/2. พจน์ส่วนกลับเข้าใกล้ศูนย์ จึงได้ 3/2
Core ประยุกต์

07. An absolute-value jump ค่าสัมบูรณ์กับการกระโดด

$$\lim_{x\to0}\frac{|x|}{x}$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. For x > 0, |x|/x = 1, so the right-hand limit is 1. เมื่อ x > 0 จะมี |x|/x = 1 ลิมิตขวาจึงเป็น 1
  2. For x < 0, |x| = −x, so the left-hand limit is −1. เมื่อ x < 0 จะมี |x| = −x ลิมิตซ้ายจึงเป็น −1
  3. The sides disagree: the two-sided limit does not exist. ทั้งสองด้านไม่เท่ากัน จึงไม่มีลิมิตสองด้าน
Core ประยุกต์

08. Squeezed oscillation การแกว่งที่ถูกบีบ

$$\lim_{x\to0}x\sin(1/x)$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. Use $|\sin(1/x)|\le1$ for $x\ne0$. ใช้ $|\sin(1/x)|\le1$ เมื่อ $x\ne0$
  2. Then $-|x|\le x\sin(1/x)\le|x|$. จึงได้ $-|x|\le x\sin(1/x)\le|x|$
  3. Both bounds tend to zero. The squeeze theorem gives 0. ขอบทั้งสองเข้าใกล้ศูนย์ ทฤษฎีบทบีบจึงให้คำตอบ 0
Core ประยุกต์

09. Exponential remainder พจน์เหลือของเอ็กซ์โพเนนเชียล

$$\lim_{x\to0}\frac{e^x-1-x}{x^2}$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. Substitution gives 0/0. Both functions are differentiable and the denominator derivative is nonzero near zero, excluding zero. แทนค่าได้ 0/0 ทั้งสองฟังก์ชันหาอนุพันธ์ได้ และอนุพันธ์ตัวส่วนไม่เป็นศูนย์ใกล้ศูนย์เมื่อยกเว้นศูนย์
  2. Apply L’Hôpital: $(e^x-1)/(2x)$, still 0/0. ใช้โลปิตาลได้ $(e^x-1)/(2x)$ ซึ่งยังเป็น 0/0
  3. Apply again: $e^x/2\to1/2$. ใช้อีกครั้งได้ $e^x/2\to1/2$
Core ประยุกต์

10. Fill a removable hole เติมค่าที่จุดขาด

$$f(x)=\begin{cases}(x^2-1)/(x-1)&x\ne1\\k&x=1\end{cases}$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. Find k that makes f continuous at 1. Factor the numerator when x ≠ 1. หา k ที่ทำให้ f ต่อเนื่องที่ 1 แยกตัวประกอบตัวเศษเมื่อ x ≠ 1
  2. The nearby formula simplifies to x + 1, whose limit at 1 is 2. สูตรรอบจุดลดรูปเป็น x + 1 ซึ่งมีลิมิตที่ 1 เท่ากับ 2
  3. Continuity requires f(1) = lim f(x), so k = 2. ความต่อเนื่องต้องมี f(1) = lim f(x) จึงได้ k = 2
Challenge ท้าทาย

11. Choose delta เลือกเดลตา

Prove using the ε–δ definition: พิสูจน์ด้วยนิยาม ε–δ:

$$\lim_{x\to1}(4x-2)=2$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. Let ε > 0 be arbitrary. The output error is |(4x−2)−2| = 4|x−1|. ให้ ε > 0 เป็นจำนวนใด ๆ ความคลาดเคลื่อนคือ |(4x−2)−2| = 4|x−1|
  2. Choose δ = ε/4. For every x with 0 < |x−1| < δ, multiply by 4. เลือก δ = ε/4 สำหรับทุก x ที่ 0 < |x−1| < δ ให้คูณด้วย 4
  3. Then |(4x−2)−2| < 4δ = ε. This is exactly the definition of the limit. ได้ |(4x−2)−2| < 4δ = ε ตรงตามนิยามลิมิต
Challenge ท้าทาย

12. A logarithmic product ผลคูณลอการิทึม

$$\lim_{x\to0^+}x\ln x$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. The form 0·(−∞) is indeterminate; rewrite it as ln(x)/(1/x). รูป 0·(−∞) ไม่กำหนด ให้เขียนเป็น ln(x)/(1/x)
  2. Apply L’Hôpital to get $(1/x)/(-1/x^2)=-x$. ใช้โลปิตาลได้ $(1/x)/(-1/x^2)=-x$
  3. As x approaches zero from the right, −x tends to zero. Answer: 0. เมื่อ x เข้าใกล้ศูนย์ด้านขวา −x เข้าใกล้ศูนย์ คำตอบคือ 0

Derivatives อนุพันธ์

Derivative · Easy อนุพันธ์ · พื้นฐาน

$$\frac{d}{dx}(4x^5-3x^2+7)$$

Step-by-step solution เฉลยทีละขั้นตอน

Apply the power rule to each term. The derivative of 4x⁵ is 20x⁴, of −3x² is −6x, and of the constant 7 is zero. Combine the terms below. ใช้กฎยกกำลังทีละพจน์ อนุพันธ์ของ 4x⁵ คือ 20x⁴ ของ −3x² คือ −6x และของค่าคงที่ 7 เป็นศูนย์ รวมพจน์ดังด้านล่าง

$$20x^4-6x$$
Derivative · Chain rule อนุพันธ์ · กฎลูกโซ่

$$\frac{d}{dx}\sin(x^2+1)$$

Step-by-step solution เฉลยทีละขั้นตอน

Outer derivative: cosine. Inner derivative: $2x$. อนุพันธ์ฟังก์ชันชั้นนอกคือ cosine และชั้นในคือ $2x$

$$2x\cos(x^2+1)$$
Derivative · Optimization อนุพันธ์ · ค่าสุดขั้ว

Find the maximum value of $f(x)=-x^2+8x-5$. หาค่าสูงสุดของ $f(x)=-x^2+8x-5$

Step-by-step solution เฉลยทีละขั้นตอน $$f'(x)=-2x+8=0\Rightarrow x=4$$ $$f(4)=-16+32-5=11$$

Since $f''(x)=-2<0$, the maximum value is $11$. เพราะ $f''(x)=-2<0$ ค่าสูงสุดคือ $11$

04. Product rule กฎผลคูณ

$$\frac{d}{dx}(x^2e^x)$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. Set u = x² and v = eˣ. Then u′ = 2x and v′ = eˣ. ให้ u = x² และ v = eˣ จะได้ u′ = 2x และ v′ = eˣ
  2. Use (uv)′ = u′v + uv′: 2xeˣ + x²eˣ. ใช้ (uv)′ = u′v + uv′ ได้ 2xeˣ + x²eˣ
  3. Factor to obtain eˣ(x² + 2x). ดึงตัวประกอบได้ eˣ(x² + 2x)
Core ประยุกต์

05. Quotient rule กฎผลหาร

$$\frac{d}{dx}\frac{x^2+1}{x-1}$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. The domain excludes x = 1. Set u = x²+1, v = x−1. โดเมนไม่รวม x = 1 ให้ u = x²+1, v = x−1
  2. Use $(u^{\prime} v-uv^{\prime})/v^2=[2x(x-1)-(x^2+1)]/(x-1)^2$. ใช้ $(u^{\prime} v-uv^{\prime})/v^2=[2x(x-1)-(x^2+1)]/(x-1)^2$
  3. Simplify: $(x^2-2x-1)/(x-1)^2$, for $x\ne1$. จัดรูปได้ $(x^2-2x-1)/(x-1)^2$ เมื่อ $x\ne1$
Core ประยุกต์

06. Logarithmic chain ลูกโซ่ลอการิทึม

$$\frac{d}{dx}\ln(1+x^2)$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. The inner function 1+x² is positive for all real x. ฟังก์ชันชั้นใน 1+x² เป็นบวกสำหรับ x จริงทุกค่า
  2. Differentiate ln u to get u′/u; here u′ = 2x. หาอนุพันธ์ ln u ได้ u′/u โดย u′ = 2x
  3. The derivative is $2x/(1+x^2)$. อนุพันธ์คือ $2x/(1+x^2)$
Core ประยุกต์

07. Tangent to a circle เส้นสัมผัสวงกลม

$$x^2+y^2=25,\quad (x,y)=(3,4)$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. Differentiate implicitly: 2x + 2yy′ = 0. หาอนุพันธ์โดยปริยาย: 2x + 2yy′ = 0
  2. Solve y′ = −x/y and substitute (3,4): slope = −3/4. แก้ได้ y′ = −x/y แล้วแทน (3,4) ความชันคือ −3/4
  3. The tangent line is $y-4=-\frac34(x-3)$. เส้นสัมผัสคือ $y-4=-\frac34(x-3)$
Challenge ท้าทาย

08. Variable exponent เลขชี้กำลังตัวแปร

$$\frac{d}{dx}x^x,\quad x>0$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. Let y = xˣ and take logs: ln y = x ln x. ให้ y = xˣ แล้วใช้ลอการิทึม: ln y = x ln x
  2. Differentiate: y′/y = ln x + 1. หาอนุพันธ์: y′/y = ln x + 1
  3. Multiply by y = xˣ: y′ = xˣ(ln x + 1). คูณด้วย y = xˣ ได้ y′ = xˣ(ln x + 1)
Challenge ท้าทาย

09. Closed-interval extrema ค่าสุดขั้วบนช่วงปิด

$$f(x)=x^3-3x,\quad x\in[-2,2]$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. Continuity guarantees global extrema. Solve f′ = 3x²−3 = 0 to find x = ±1. ความต่อเนื่องรับประกันค่าสุดขั้วสัมบูรณ์ แก้ f′ = 3x²−3 = 0 ได้ x = ±1
  2. Evaluate at both critical points and endpoints: f(−2)=−2, f(−1)=2, f(1)=−2, f(2)=2. คำนวณทั้งจุดวิกฤตและปลายช่วง: f(−2)=−2, f(−1)=2, f(1)=−2, f(2)=2
  3. Maximum 2 at −1 and 2; minimum −2 at −2 and 1. ค่าสูงสุด 2 ที่ −1 และ 2 ค่าต่ำสุด −2 ที่ −2 และ 1
Core ประยุกต์

10. Mean value point จุดค่ากลาง

$$f(x)=x^2,\quad [1,3]$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. The function is continuous on [1,3] and differentiable on (1,3), so the MVT applies. ฟังก์ชันต่อเนื่องบน [1,3] และหาอนุพันธ์ได้บน (1,3) จึงใช้ทฤษฎีบทค่ากลางได้
  2. The average slope is (9−1)/(3−1) = 4. ความชันเฉลี่ยคือ (9−1)/(3−1) = 4
  3. Solve f′(c) = 2c = 4 to obtain c = 2, inside the interval. แก้ f′(c) = 2c = 4 ได้ c = 2 ซึ่งอยู่ภายในช่วง

11. Related rates: sphere อัตราสัมพัทธ์: ทรงกลม

$$V=\frac43\pi r^3,\quad r=3\;\mathrm{cm},\quad \frac{dr}{dt}=2\;\mathrm{cm/s}$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. Differentiate the volume formula with respect to time before substituting the radius. หาอนุพันธ์สูตรปริมาตรเทียบกับเวลาก่อนแทนรัศมี
  2. $dV/dt=4\pi r^2\,dr/dt$. $dV/dt=4\pi r^2\,dr/dt$
  3. Substitute: $4\pi(3)^2(2)=72\pi\;\mathrm{cm^3/s}$. แทนค่า: $4\pi(3)^2(2)=72\pi\;\mathrm{cm^3/s}$
Foundation พื้นฐาน

12. Local approximation การประมาณใกล้จุด

Approximate using the tangent at x = 4: ประมาณด้วยเส้นสัมผัสที่ x = 4:

$$\sqrt{4.1}$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. Choose f(x) = √x. At a = 4, f(a) = 2 and f′(a) = 1/4. เลือก f(x) = √x ที่ a = 4 มี f(a) = 2 และ f′(a) = 1/4
  2. Build L(x) = 2 + (x−4)/4. สร้าง L(x) = 2 + (x−4)/4
  3. L(4.1) = 2.025. This is an approximation; concavity down means the tangent overestimates. L(4.1) = 2.025 เป็นค่าประมาณ กราฟเว้าลงจึงได้ค่ามากกว่าค่าจริง

Integrals ปริพันธ์

Integral · Easy ปริพันธ์ · พื้นฐาน

$$\int(6x^2-4x+3)dx$$

Step-by-step solution เฉลยทีละขั้นตอน

Integrate term by term: increase each power by one and divide by the new power. This gives 6x³/3 − 4x²/2 + 3x. Add an arbitrary constant C. อินทิเกรตทีละพจน์ เพิ่มเลขชี้กำลังหนึ่งแล้วหารด้วยกำลังใหม่ ได้ 6x³/3 − 4x²/2 + 3x แล้วบวกค่าคงที่ C

$$2x^3-2x^2+3x+C$$
Integral · Substitution ปริพันธ์ · การแทนค่า

$$\int 2x e^{x^2}dx$$

Step-by-step solution เฉลยทีละขั้นตอน

Let $u=x^2$, $du=2x\,dx$. ให้ $u=x^2$, $du=2x\,dx$

$$\int e^u du=e^u+C=e^{x^2}+C$$
Integral · Definite ปริพันธ์ · จำกัดเขต

$$\int_0^2(3x^2+1)dx$$

Step-by-step solution เฉลยทีละขั้นตอน

An antiderivative of 3x² + 1 is x³ + x. Use the FTC: evaluate at 2, then subtract its value at 0. Both bounds lie in the continuous domain. ปฏิยานุพันธ์ของ 3x² + 1 คือ x³ + x ใช้ทฤษฎีบทมูลฐาน แทน 2 แล้วลบค่าที่ 0 ขอบทั้งสองอยู่ในโดเมนที่ต่อเนื่อง

$$\left[x^3+x\right]_0^2=8+2=10$$

04. Integration by parts อินทิเกรตโดยส่วน

$$\int xe^x\,dx$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. Choose u = x and dv = eˣ dx, so du = dx and v = eˣ. เลือก u = x และ dv = eˣ dx จึงได้ du = dx และ v = eˣ
  2. Use $\int u\,dv=uv-\int v\,du$ to get $xe^x-\int e^x dx$. ใช้ $\int u\,dv=uv-\int v\,du$ ได้ $xe^x-\int e^x dx$
  3. The result is eˣ(x−1) + C. Differentiate it to check: xeˣ. ผลคือ eˣ(x−1) + C หาอนุพันธ์ตรวจสอบได้ xeˣ
Core ประยุกต์

05. Recognize a logarithm มองหารูปลอการิทึม

$$\int\frac{2x}{1+x^2}\,dx$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. Set u = 1+x², so du = 2x dx. ให้ u = 1+x² จึงได้ du = 2x dx
  2. The integral becomes $\int du/u=\ln|u|+C$. ปริพันธ์เป็น $\int du/u=\ln|u|+C$
  3. Since 1+x² > 0, the answer is ln(1+x²) + C. เพราะ 1+x² > 0 คำตอบคือ ln(1+x²) + C
Core ประยุกต์

06. Trigonometric power กำลังตรีโกณมิติ

$$\int\sin^2x\,dx$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. Use the identity sin²x = (1−cos 2x)/2. ใช้เอกลักษณ์ sin²x = (1−cos 2x)/2
  2. Integrate the constant term as x/2. The cosine term needs a factor 1/2 from its inner derivative. อินทิเกรตพจน์คงที่ได้ x/2 พจน์ cosine ต้องคูณ 1/2 จากอนุพันธ์ชั้นใน
  3. The answer is $x/2-\sin(2x)/4+C$. คำตอบคือ $x/2-\sin(2x)/4+C$
Challenge ท้าทาย

07. Partial fractions เศษส่วนย่อย

$$\int\frac{dx}{x^2-1}$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. Factor the denominator: $(x-1)(x+1)$, excluding $x=\pm1$. แยกตัวส่วนเป็น $(x-1)(x+1)$ โดยไม่รวม $x=\pm1$
  2. Solve $1=A(x+1)+B(x-1)$: $A=1/2$, $B=-1/2$. แก้ $1=A(x+1)+B(x-1)$ ได้ $A=1/2$, $B=-1/2$
  3. Integrate: $\frac12\ln|x-1|-\frac12\ln|x+1|+C$, on each interval of the domain. อินทิเกรตได้ $\frac12\ln|x-1|-\frac12\ln|x+1|+C$ แยกในแต่ละช่วงของโดเมน
Foundation พื้นฐาน

08. Signed integral versus area ปริพันธ์แบบมีเครื่องหมายกับพื้นที่

$$f(x)=x,\quad [-1,1]$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. The signed integral is $[x^2/2]_{-1}^1=0$. ปริพันธ์แบบมีเครื่องหมายคือ $[x^2/2]_{-1}^1=0$
  2. For geometric area, split at zero and negate the part below the axis. สำหรับพื้นที่เรขาคณิต ให้แบ่งที่ศูนย์แล้วเปลี่ยนเครื่องหมายส่วนใต้แกน
  3. $A=-\int_{-1}^0x\,dx+\int_0^1x\,dx=1/2+1/2=1$. $A=-\int_{-1}^0x\,dx+\int_0^1x\,dx=1/2+1/2=1$
Core ประยุกต์

09. Area between curves พื้นที่ระหว่างเส้นโค้ง

$$y=x,\quad y=x^2$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. Find intersections from x = x²: x = 0 and x = 1. หาจุดตัดจาก x = x² ได้ x = 0 และ x = 1
  2. On [0,1], x ≥ x². Integrate upper minus lower. บน [0,1] มี x ≥ x² ให้หาปริพันธ์เส้นบนลบเส้นล่าง
  3. $A=\int_0^1(x-x^2)dx=[x^2/2-x^3/3]_0^1=1/6$. $A=\int_0^1(x-x^2)dx=[x^2/2-x^3/3]_0^1=1/6$
Core ประยุกต์

10. Variable upper bound ขอบบนเป็นตัวแปร

$$\frac{d}{dx}\int_0^{x^2}\cos t\,dt$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. The integrand is continuous, so the FTC applies. ฟังก์ชันใต้ปริพันธ์ต่อเนื่อง จึงใช้ทฤษฎีบทมูลฐานได้
  2. Evaluate the integrand at the upper bound: cos(x²). แทนขอบบนลงในฟังก์ชันใต้ปริพันธ์: cos(x²)
  3. Multiply by the upper-bound derivative 2x. Answer: 2x cos(x²). คูณด้วยอนุพันธ์ขอบบน 2x คำตอบคือ 2x cos(x²)
Challenge ท้าทาย

11. A convergent improper integral ปริพันธ์ไม่ตรงแบบที่ลู่เข้า

$$\int_1^{\infty}\frac{dx}{x^2}$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. Replace infinity by $R$ and plan to take $R\to\infty$. แทนอนันต์ด้วย $R$ แล้วเตรียมหาลิมิต $R\to\infty$
  2. $\int_1^R x^{-2}dx=[-1/x]_1^R=1-1/R$. $\int_1^R x^{-2}dx=[-1/x]_1^R=1-1/R$
  3. The limit is 1, so the improper integral converges to 1. ลิมิตคือ 1 ปริพันธ์ไม่ตรงแบบจึงลู่เข้าเท่ากับ 1
Challenge ท้าทาย

12. A divergent singularity จุดเอกฐานที่ลู่ออก

$$\int_{-1}^1\frac{dx}{x}$$
Step-by-step solution เฉลยทีละขั้นตอน
  1. Split at zero, where the integrand is undefined. Each side must converge independently. แบ่งที่ศูนย์ซึ่งฟังก์ชันไม่นิยาม แต่ละด้านต้องลู่เข้าแยกกัน
  2. $\int_\varepsilon^1dx/x=-\ln\varepsilon\to+\infty$ as $\varepsilon\to0^+$. $\int_\varepsilon^1dx/x=-\ln\varepsilon\to+\infty$ เมื่อ $\varepsilon\to0^+$
  3. Already one side diverges, so the improper integral diverges. Symmetric cancellation does not fix it. ด้านเดียวลู่ออกก็สรุปว่าปริพันธ์ลู่ออกได้แล้ว การหักล้างแบบสมมาตรแก้ไม่ได้
